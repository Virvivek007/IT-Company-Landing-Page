# IT-Company-Landing-Page
A fast, accessible landing page for ProdeskIT, a software IT company offering website development, SEO &search strategy, and digital marketing services.

Live site: https://it-company-landing-page-gamma.vercel.app/

<img src= "[webPage_Screenshot.png](https://github.com/Virvivek007/IT-Company-Landing-Page/blob/main/webPage_Screenshot%20.png)" />

## Tech Stack

- HTML5
- CSS3 (custom properties for theming, CSS Grid & Flexbox, no framework)
- Vanilla JavaScript (no dependencies)
- Fonts: Google Fonts (Roboto, Space Grotesk)
- Hosted on [Vercel][(https://vercel.com/](https://it-company-landing-page-gamma.vercel.app/))
